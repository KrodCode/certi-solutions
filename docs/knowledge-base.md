# Base de conocimiento de Certi-Solutions

## Propósito

La base de conocimiento contiene información ficticia y académica relacionada con procesos generales de certificación de productos.

El agente utilizará estos documentos para responder preguntas en lenguaje natural sin consultar información confidencial de empresas reales.

## Documentación contemplada

### Proceso de certificación

Incluye información sobre:

- Ingreso de una solicitud.
- Revisión documental.
- Evaluación técnica.
- Ejecución de ensayos.
- Emisión de resultados.
- Cierre del proceso.

### Requisitos documentales

Incluye información sobre:

- Identificación del solicitante.
- Identificación del producto.
- Fichas técnicas.
- Manuales de uso.
- Informes de ensayo.
- Declaraciones y certificados previos.
- Antecedentes faltantes.

### Seguimiento de solicitudes

Incluye información sobre:

- Estados de una solicitud.
- Consultas de avance.
- Antecedentes pendientes.
- Observaciones técnicas.
- Plazos estimados.
- Actualización de documentos.

### Ensayos y evaluaciones técnicas

Incluye información sobre:

- Recepción de muestras.
- Asignación de ensayos.
- Resultados conformes.
- Resultados no conformes.
- Repetición de evaluaciones.
- Emisión de informes.

### No conformidades y correcciones

Incluye información sobre:

- Registro de observaciones.
- Solicitud de antecedentes adicionales.
- Corrección de documentación.
- Subsanación de incumplimientos.
- Reevaluación del producto.

### Preguntas frecuentes

El agente podrá responder preguntas como:

- ¿Cómo se inicia una certificación?
- ¿Qué documentos se deben presentar?
- ¿Cómo se consulta el estado de una solicitud?
- ¿Qué ocurre si falta documentación?
- ¿Cómo se corrige una no conformidad?
- ¿Cuándo se emite el resultado final?

## Formato inicial

La primera versión utilizará un archivo CSV ficticio.

Posteriormente se podrá incorporar procesamiento de documentos PDF.

## Restricciones de seguridad

Los documentos no deben contener:

- Datos personales reales.
- Información de clientes reales.
- Números de certificados reales.
- Direcciones internas.
- Direcciones IP.
- Credenciales.
- Contraseñas.
- Tokens.
- Claves de API.
- Información empresarial confidencial.
