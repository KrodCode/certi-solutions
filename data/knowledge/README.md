# Documentos de conocimiento

Esta carpeta almacena los documentos utilizados por el agente inteligente de Certi-Solutions.

## Formatos contemplados

- CSV.
- PDF.

## Primera implementación

La primera versión utilizará un archivo CSV ficticio que incluirá:

- Categoría.
- Pregunta.
- Respuesta.
- Palabras clave.
- Fuente documental.

## Reglas de seguridad

Solo se deben incorporar documentos:

- Públicos.
- Ficticios.
- Anonimizados.
- Creados para fines académicos.
- Libres de credenciales.
- Libres de información confidencial.

No se deben incorporar:

- Documentos internos de empresas.
- Datos personales.
- Información de clientes reales.
- Claves de acceso.
- Configuraciones privadas.
- Direcciones de infraestructura.
- Respaldos de bases de datos.
