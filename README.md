# Certi-Solutions

Agente inteligente orientado a responder consultas en lenguaje natural sobre procesos y documentación de certificación de productos.

Proyecto desarrollado para el Challenge Alura Agente.

## Estado

Proyecto en etapa inicial de desarrollo.

## Seguridad

Las credenciales, variables de entorno, claves de API y configuraciones privadas no se almacenan en el repositorio. La configuración se realiza mediante variables de entorno locales y servicios seguros de OCI.
